HƯỚNG DẪN SỬ DỤNG PORTAL TPCLOUDUSING THE TPCLOUD PORTAL

Đăng nhập Portal và tạo OrgVDC Network: Isolated Network, Routed Network, cấu hình DHCP.Logging in to the Portal and creating OrgVDC Networks: Isolated Network, Routed Network, and DHCP configuration.

Portal TPCLOUD là cổng giao diện dùng để quản trị dịch vụ Cloud của TPCOMS, giúp thực hiện các thao tác cơ bản như cấu hình network, cấu hình tạo VM và quản lý VM, cũng như các tác vụ liên quan đến quản lý user, monitor hệ thống... Giao diện Portal nhiều tính năng mới và thân thiện với người dùng. Sơ đồ quy trình sử dụng Portal Cloud cơ bản:The TPCLOUD Portal is the interface used to administer the TPCOMS Cloud service. It supports basic operations such as configuring networks, creating and managing VMs, as well as tasks related to user management and system monitoring... The Portal interface offers many new and user-friendly features. The basic Cloud Portal workflow diagram:

2.1ĐĂNG NHẬP PORTAL TPCLOUDLOGGING IN TO THE TPCLOUD PORTAL

Truy cập portal TPCLOUD theo đường dẫn và thông tin đăng nhập đã được TPCOMS cung cấp qua email. Đường dẫn truy cập có định dạng:Access the TPCLOUD Portal using the URL and login credentials provided by TPCOMS via email. The access URL has the format:

🔗https://console-01.tpcloud.vn/tenant/organization_name

Với organization_name được thay đổi theo thông tin khách hàng. Mỗi Khách hàng sẽ được phân tách thành các chủ thể riêng biệt thường được gọi là Organization. Tài nguyên được tổ chức thành các trung tâm dữ liệu ảo (Virtual Data Center - VDC) riêng biệt cho từng khách hàng.Where organization_name is changed according to the customer's information. Each customer is separated into a distinct entity commonly called an Organization. Resources are organized into separate Virtual Data Centers (VDC) for each customer.

Sau khi truy cập vào trang đăng nhập do TPCOMS cung cấp người dùng tiến hành nhập User name và Password đã được TPCOMS cung cấp qua email.After accessing the login page provided by TPCOMS, the user enters the User name and Password provided by TPCOMS via email.

Sau khi đăng nhập thành công, từ màn hình quản trị chính người dùng có thể xem được các thông số tổng quát trong Datacenter ảo như: Site, vApp, VM, tài nguyên cấp phát, tài nguyên đã dùng,...After logging in successfully, from the main administration screen the user can view general parameters of the virtual Datacenter such as: Site, vApp, VM, allocated resources, used resources, etc.

2.2TẠO ORGVDC NETWORKCREATING AN ORGVDC NETWORK

Network type hỗ trợ 2 kiểu kết nối:The network type supports 2 connection modes:

  • Isolated: dạng cô lập nội bộ giữa các VM, hoàn toàn không có kết nối ra bên ngoài.Isolated: an internally isolated mode between VMs, with no connection to the outside at all.
  • Routed: Kết nối với vFirewall/VLB, các VM sẽ truy cập có kiểm soát ra mạng bên ngoài thông qua NAT và Firewall rule.Routed: connected to the vFirewall/VLB; VMs access the external network in a controlled manner through NAT and Firewall rules.

2.2.1TẠO ISOLATED NETWORKCREATING AN ISOLATED NETWORK

Các bước tạo Isolated Network:Steps to create an Isolated Network:

  • Tại Portal TPCLOUD chọn Networking → Networks → NEW.In the TPCLOUD Portal, select Networking → Networks → NEW.
  • Tại cửa sổ New Organization VDC Network mục Scope tích chọn Organization VDC cần tạo network sau đó nhấn NEXT.In the New Organization VDC Network window, under Scope, select the Organization VDC where the network is to be created, then click NEXT.
  • Tại phần Network Type tích chọn type là Isolated sau đó nhấn NEXT.Under Network Type, select the type as Isolated, then click NEXT.
  • Tại phần General tiến hành nhập Name và Gateway CIDR sau đó nhấn NEXT.Under General, enter the Name and Gateway CIDR, then click NEXT.
  • Tại phần Static IP Pools tiến hành nhập các range Static IP Pool nếu cần và nhấn NEXT.Under Static IP Pools, enter the Static IP Pool ranges if needed, then click NEXT.
  • Tại phần DNS tiến hành nhập DNS sau đó nhấn NEXT.Under DNS, enter the DNS, then click NEXT.
  • Tại phần Ready to Complete xem lại thông tin network vừa cấu hình sau đó nhấn FINISH để hoàn thành quá trình khởi tạo network.Under Ready to Complete, review the network information just configured, then click FINISH to complete the network creation process.
  • Sau khi tạo xong người dùng sẽ thấy một network mới được tạo ra trên bảng danh sách network.Once created, the user will see a new network added to the network list.

2.2.2TẠO ROUTED NETWORKCREATING A ROUTED NETWORK

Routed Network là network được tạo ra nhằm sử dụng cho các VM trong VDC hoặc VDC group. Chúng được quản lý thông quan Edge Gateway.A Routed Network is a network created for use by VMs within a VDC or VDC group. They are managed through the Edge Gateway.

Edge Gateway đóng vai trò như một router ảo nhằm quản lý các network được gắn vào nó và đồng thời cung cấp các dịch vụ như Firewall, NAT, Routing, VPN, Load Balancer,…. Được TPCOMS cung cấp miễn phí đến người dùng. Các bước tạo Routed Network:The Edge Gateway acts as a virtual router that manages the networks attached to it and also provides services such as Firewall, NAT, Routing, VPN, Load Balancer, etc. It is provided free of charge to users by TPCOMS. Steps to create a Routed Network:

  • Tại Portal TPCLOUD chọn Networking → Networks → NEW.In the TPCLOUD Portal, select Networking → Networks → NEW.
  • Tại cửa sổ New Organization VDC Network mục Scope tích chọn Organization VDC cần tạo network sau đó nhấn NEXT.In the New Organization VDC Network window, under Scope, select the Organization VDC where the network is to be created, then click NEXT.
  • Tại phần Network Type tích chọn Type là Routed sau đó nhấn NEXT.Under Network Type, select the Type as Routed, then click NEXT.
  • Tại phần Edge Connection chọn Edge mà network này kết nối vào sau đó nhấn NEXT.Under Edge Connection, select the Edge that this network connects to, then click NEXT.
  • Tại phần General nhập Name của network và Gateway CIDR sau đó nhấn NEXT.Under General, enter the network Name and Gateway CIDR, then click NEXT.
  • Tại phần Static IP Pools nhập range static IP Pool muốn cấu hình và nhấn NEXT.Under Static IP Pools, enter the static IP Pool range you want to configure, then click NEXT.
  • Tại phần DNS tiến hành cấu hình DNS và nhấn NEXT.Under DNS, configure the DNS, then click NEXT.
  • Tại phần Ready to Complete tiến hành xem lại các thông tin đã cấu hình trước đó và nhấn FINISH để hoàn thành quá trình khởi tạo network.Under Ready to Complete, review the previously configured information and click FINISH to complete the network creation process.
  • Sau khi hoàn thành tạo Routed Network trên danh sách network sẽ xuất hiện routed network vừa được tạo.After completing the Routed Network creation, the newly created routed network will appear in the network list.

2.2.3CẤU HÌNH DHCPCONFIGURING DHCP

Để cấu hình DHCP ta thực hiện các bước sau:To configure DHCP, perform the following steps:

  • Tại trang quản lý network ta chọn network cần cấu hình DHCP.On the network management page, select the network for which DHCP is to be configured.
  • Tiếp tục chọn mục DHCP → ACTIVE.Next, select DHCP → ACTIVE.
  • Tại phần General Settings cấu hình DHCP Mode chọn Gateway sau đó nhấn NEXT.Under General Settings, configure the DHCP Mode by selecting Gateway, then click NEXT.
  • Tại phần DHCP Pools nhấn add và nhập range IP pools sau đó nhấn NEXT.Under DHCP Pools, click add and enter the IP pool range, then click NEXT.
  • Tại phần DNS through DHCP nhập DNS Server sau đó nhấn NEXT.Under DNS through DHCP, enter the DNS Server, then click NEXT.
  • Kiểm tra lại cấu hình sau đó nhấn FINISH để hoàn thành cấu hình DHCP.Review the configuration, then click FINISH to complete the DHCP configuration.
  • DHCP đã cấu hình cho NETWORK-ROUTED.DHCP has been configured for NETWORK-ROUTED.

TẠO VÀ QUẢN LÝ VAPPCREATING AND MANAGING vApps

Tạo và quản lý vApp: tạo vApp mới, tạo từ file OVF, tạo từ Catalog và thêm network.Creating and managing vApps: a new vApp, from an OVF file, from a Catalog, and adding networks.

vApp là một khối logic cho phép quản lý các VM và tài nguyên khác nhau như một khối duy nhất, giúp việc triển khai, khởi động, và quản lý đơn giản hơn.A vApp is a logical unit that allows different VMs and resources to be managed as a single unit, making deployment, startup, and management simpler.

3.1TẠO MỚI VAPPCREATING A NEW vApp

Để tạo vAPP ta thực hiện các bước sau:To create a vApp, perform the following steps:

  • Trên giao diện Portal CLOUD chọn Applications → Virtual Applications → NEW VAPP.On the CLOUD Portal interface, select Applications → Virtual Applications → NEW VAPP.
  • Tại cửa sổ Select Target Virtual Data Center tích chọn ORGVDC để tạo vAPP sau đó nhấn NEXT.In the Select Target Virtual Data Center window, select the ORGVDC where the vApp is to be created, then click NEXT.
  • Tại cửa sổ New vApp nhập Name của vApp, nhập Description (nếu cần), tích vào ô check box Power on nếu muốn vApp được bật sau khi tạo sau đó nhấn CREATE.In the New vApp window, enter the vApp Name, enter a Description (if needed), tick the Power on check box if you want the vApp to be powered on after creation, then click CREATE.
  • Sau khi tạo vApp người dùng sẽ thấy được vApp vừa tạo hiện lên trên danh sách vApp.After creating the vApp, the user will see the newly created vApp appear in the vApp list.

3.2TẠO VAPP TỪ FILE OVFCREATING A vApp FROM AN OVF FILE

Các file được đóng gói dưới dạng OVF giúp máy ảo được triển khai dễ dàng trên các nền tảng khác nhau mà không cần cấu hình lại, tiết kiệm thời gian đồng thời giảm thiểu lỗi phát sinh do không tương thích. Với cách này ta cần download sẵn file OVF về máy local. Để tạo vApp từ OVF ta thực hiện các bước sau:Files packaged in OVF format make it easy to deploy virtual machines on different platforms without reconfiguration, saving time while minimizing errors caused by incompatibility. With this method, you need to download the OVF file to the local machine in advance. To create a vApp from an OVF file, perform the following steps:

  • Tại trang quản lý vApp chọn NEW → Add vApp From OVF.On the vApp management page, select NEW → Add vApp From OVF.
  • Chọn vào ORGVDC-NAME rồi nhấn NEXTSelect the ORGVDC-NAME, then click NEXT.
  • Tại cửa sổ Create a vApp from An OVF file nhấn vào icon chọn source OVF để tạo vApp.In the Create a vApp from An OVF file window, click the icon to select the source OVF for creating the vApp.
  • Chọn file OVF → nhấn Open.Select the OVF file → click Open.
  • Sau khi chọn được file OVF ta tiến hành cấu hình các bước còn lại để hoàn thành cấu hình tạo vApp.After selecting the OVF file, proceed to configure the remaining steps to complete the vApp creation.
  • VM được tạo bởi vApp From OVF.VM created by vApp From OVF.

3.3TẠO VAPP TỪ CATALOGCREATING A vApp FROM A CATALOG

vApp Templates là các phiên bản tiêu chuẩn lưu trữ trong Catalog được nhà cung cấp tạo sẵn. vApp Templates bao gồm các hệ điều hành, phần mềm và cấu hình đã được kiểm thử.vApp Templates are standard versions stored in the Catalog, pre-created by the provider. vApp Templates include operating systems, software, and configurations that have been tested.

Khi triển khai từ Catalog cho phép người dùng triển khai nhanh chóng một vApp hoàn chỉnh từ các mẫu đã được kiểm tra và chuẩn bị trước, các vApp luôn giữ được tính đồng nhất trong cấu hình và tính năng, giúp giảm thiểu lỗi và đảm bảo rằng tất cả người dùng đều làm việc trên cùng một nền tảng tiêu chuẩn. Để tạo vApp từ Catalog ta thực hiện các bước sau:Deploying from a Catalog allows users to quickly deploy a complete vApp from pre-tested and prepared templates. The vApps always maintain consistency in configuration and features, helping to minimize errors and ensure that all users work on the same standard platform. To create a vApp from a Catalog, perform the following steps:

  • Tại trang quản lý vApp chọn NEW → Add vApp From Catalog.On the vApp management page, select NEW → Add vApp From Catalog.
  • Tại cửa sổ Create vApp from Template ta chọn Template theo nhu cầu sử dụng và nhấn NEXT.In the Create vApp from Template window, select the Template according to your needs, then click NEXT.
  • Tiến hành cấu hình các bước tiếp theo tùy theo setup của từng Template để hoàn thành quá trình tạo vApp.Proceed with the next configuration steps depending on the setup of each Template to complete the vApp creation process.
  • VM được tạo bởi vApp From Catalog.VM created by vApp From Catalog.

3.4THÊM ORGVDC NETWORK VÀO VAPPADDING AN ORGVDC NETWORK TO A vApp

Việc thêm Network vào vApp giúp các VM thuộc vApp có thể sử dụng. Các bước thêm network vào vApp như sau:Adding a Network to a vApp allows the VMs belonging to the vApp to use it. The steps to add a network to a vApp are as follows:

  • Trên vApp ta chọn ACTIONS → Add → Add Network.On the vApp, select ACTIONS → Add → Add Network.
  • Tại cửa sổ Add Network chọn loại Network của vApp là Direct → tích chọn network cần thêm vào vApp sau đó nhấn ADD.In the Add Network window, select the vApp Network type as Direct → tick the network to be added to the vApp, then click ADD.
  • Sau khi thêm network vào vApp người dùng có thể xem các network trên vApp bằng cách chọn DETAILS của vApp.After adding the network to the vApp, the user can view the networks on the vApp by selecting DETAILS of the vApp.
  • Chọn tab Networks để xem các network trên vApp cũng như có thể chỉnh sửa, cấu hình network ở giao diện này.Select the Networks tab to view the networks on the vApp, where you can also edit and configure the network in this interface.

TẠO VÀ QUẢN LÝ MÁY ẢOCREATING AND MANAGING VIRTUAL MACHINES

Tạo máy ảo từ file ISO và từ Template (Ubuntu, Windows Server), quản lý cấu hình và snapshot VM.Creating VMs from ISO files and Templates (Ubuntu, Windows Server), managing VM configuration and snapshots.

4.1TẠO MÁY ẢO TỪ FILE ISOCREATING A VM FROM AN ISO FILE

Việc cài đặt từ file ISO giúp quản trị viên tùy chỉnh cài đặt ngay từ đầu, từ phiên bản hệ điều hành đến các thành phần và phần mềm cài đặt kèm theo. Điều này rất hữu ích khi muốn kiểm soát chi tiết quá trình cài đặt và có các yêu cầu đặc biệt về hệ thống. Để tạo máy ảo từ file iso ta thực hiện các bước sau:Installing from an ISO file allows the administrator to customize the installation from the start, from the operating system version to the bundled components and software. This is very useful when you want detailed control over the installation process and have special system requirements. To create a virtual machine from an ISO file, perform the following steps:

  • Tại trang quản lý VM chọn NEW VM.On the VM management page, select NEW VM.
  • Nhập thông tin Name, Computer Name.Enter the Name and Computer Name information.
  • Type chọn là New để cài đặt từ file iso.Set Type to New to install from an ISO file.
  • Bỏ tích chọn Power on để khi setup xong VM ở trạng thái off ta có thể enable tính năng tăng nóng CPU và RAM.Untick Power on so that, after setup is complete, the VM is in the off state and you can enable the CPU and RAM hot-add feature.
  • Operating System lựa chọn phù hợp với OS ủa VM cần cài.Select the Operating System matching the OS of the VM to be installed.
  • Thông số Boot Options để mặc định.Leave the Boot Options parameters at default.
  • Compute: nhập thống số cấu hình phù hợp với nhu cầu sử dụng.Compute: enter configuration parameters matching your usage needs.
  • Storage: Storage Policy để mặc định và nhập dung lượng ổ cứng theo nhu cầu vào ô size.Storage: leave the Storage Policy at default and enter the hard disk capacity as needed in the size field.
  • Tại mục Networking ta chọn Network cần dùng và điều chỉnh các thông số theo nhu cầu sử dụng.Under Networking, select the Network to be used and adjust the parameters according to your usage needs.
  • Sau khi hoàn chỉnh các thống số cấu hình ta nhấn OK để tiến hành tạo VM.After completing the configuration parameters, click OK to proceed with creating the VM.
  • Enable tính năng Virtual CPU hot add và Memory hot add để cho phép VM có thể tăng nóng CPU và RAM khi VM đang hoạt động.Enable the Virtual CPU hot add and Memory hot add features to allow the VM to hot-add CPU and RAM while the VM is running.
